# Unity en Ubuntu

1. Abrir Unity Hub e iniciar sesión.
2. Instalar una versión Unity LTS compatible con Linux.
3. Marcar Android Build Support, Android SDK & NDK Tools y OpenJDK.
4. Crear proyecto 2D llamado TrucoPy.
5. Clonar este repositorio y conservar las carpetas Assets/Scripts existentes.
6. Copiar/guardar en Git las carpetas Packages y ProjectSettings generadas por Unity.
7. Abrir proyecto desde Unity Hub y comprobar consola sin errores.

**Nota:** los scripts de este repositorio son una base de lógica, no constituyen todavía un proyecto Unity completo ni una partida jugable. No publicar anuncios reales durante desarrollo: usar IDs de prueba.
