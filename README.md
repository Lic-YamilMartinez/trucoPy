# Truco Paraguayo 🇵🇾

MVP de juego de cartas para Android, desarrollado en Unity/C#, jugable sin conexión con rivales CPU.

## Alcance inicial
- Menú principal y selección de personaje
- Partidas individuales contra IA, con arquitectura extensible a parejas
- Reglas de truco paraguayo a documentar y validar antes de implementarlas
- 4–5 personajes ficticios inspirados en arquetipos paraguayos
- Publicidad opcional cuando exista conexión, sin impedir juego offline

## Estado
Repositorio inicial. No contiene aún un proyecto Unity generado por el editor ni una versión jugable.

## Próximos pasos
1. Instalar Unity Hub y editor LTS con Android Build Support en Ubuntu.
2. Crear proyecto 2D con Unity y subir `Assets`, `Packages` y `ProjectSettings`.
3. Validar reglas y construir motor determinista con pruebas.
4. Añadir CPU, escenas, personajes y anuncios.

Ver `Docs/ROADMAP.md` para el plan.
